Browser Interaction: alert(), prompt(), confirm()

JavaScript provides three modal dialog functions that run directly inside the browser environment. These functions are synchronous and blocking: they pause code execution and prevent the user from interacting with the rest of the page until the dialog box is dismissed.

1. Alert Dialog: alert(message)

Shows a message dialog box with an "OK" button. It returns no value (returns undefined).

2. Confirm Dialog: confirm(question)

Shows a question with "OK" and "Cancel" buttons. Returns true if OK is clicked, and false if Cancel is clicked.

3. Prompt Dialog: prompt(title, [default])

Shows a dialog box with a text input field, an "OK" button, and a "Cancel" button. Returns the entered text (string) if OK is clicked, or null if Cancel is clicked.
